 📊 Excel Salary Analysis Project

This project analyzes salary data using Excel.

 Functions Used

- AVERAGEIF → Average salary by job role  
- SUMIF → Total salary by job role  
- COUNTIF → Count of employees per role  
- IF → Categorized salary (High / Low)  
- COUNTIFS → Count based on multiple conditions  
- SUMIFS → Total salary with conditions  
- AVERAGEIFS → Average salary with conditions  
- MAX / MIN → Highest and lowest salary  
- UNIQUE → Extract unique job titles  
- CONCAT → Combine text values  

 Insights

- Identified highest paying roles  
- Compared remote vs non-remote salaries  
- Categorized salary levels
